deepseek-2api 性能架构报告

2026-05-28 · PoW+Session 并行 · Token 池并发 · Session 3 天缓存

架构背景

deepseek-2api 将 DeepSeek 官网聊天接口转为 OpenAI 兼容 API。每次请求需 获取 Token → 解 PoW → 创建/复用 Session → 拉取 HIF 令牌 → 发起补全。不同于 glm-2api 的浏览器验证码方案，deepseek-2api 纯 HTTP 交互，核心开销在 PoW 计算和会话管理。
冷启动（首次请求 / 缓存全未命中）
Token 获取~0ms
PoW 计算50–200ms
Session 创建200–500ms
HIF 令牌获取100–300ms
Completion 请求流式 1–60s
请求前开销350–1000ms
热路径（缓存命中）
Token 获取~0ms
PoW 计算50–200ms
Session 复用~0ms
HIF 令牌缓存~0ms
Completion 请求流式 1–60s

已有优化一览

① WASM PoW 求解器
50–200ms · BigInt 回退
sha3_wasm_bg.wasm 一次加载，BigInt 求解器作为 fallback
② Session 3 天缓存 + 预热
省 200–500ms/请求
sessionPool Map 缓存，启动时 prewarmSessions() 批量预建
③ HIF 令牌缓存
省 100–300ms/请求
hifCache 按 token 缓存 leim+dliq，TTL 自动续期
④ Token 池 + 最小负载选择
每 token 2 并发
acquireToken() 按 activeRequests 排序，优先选最少负载
⑤ FIFO 请求队列
上限 100 · 30s 超时
即时获取 fast-path + 排队等待，dispatchQueued() 释放时派发
⑥ Token 持久化到 .env
防重启丢失
persistTokensToEnv() 存活 token 写入 DS_TOKENS= 行
⑦ 定时健康检查
10 分钟间隔
仅检查空闲 >30min 的 token，失效自动刷新或标记 dead
⑧ Proxy 支持
绕 IP 限速
undici ProxyAgent，HTTPS_PROXY 环境变量配置

待优化项

⑨ PoW + Session 并行
省 200–500ms · 中风险
当前串行：solvePow → getSession；Session 创建不需要 PoW 结果，可 Promise.all
⑩ Vision 上传双重获取
省 1 次队列等待 · 低风险
openai.js 先 acquire 上传图片再 release，然后 completion 再次 acquire — 可复用同一 slot
⑪ HIF 预取
省 100–300ms 首次 · 低风险
启动时随 session 预热一起获取 HIF 令牌，首次请求零延迟
⑫ HTTP 连接复用
省 TLS 握手 · 低风险
undici 默认复用，但 proxiedFetch 与直接 fetch 不共享连接池

const sessionPool = new Map(); // key: token:model_type
const SESSION_TTL = 259200; // 3 days in seconds

export async function getSession(token, modelType) {
  const cacheKey = `${token.slice(0, 12)}:${modelType}`;
  const cached = sessionPool.get(cacheKey);
  if (cached && (now - cached.createdAt) < SESSION_TTL) return cached;

  const session = await createSession(token, modelType);
  sessionPool.set(cacheKey, session);
  return session;
}

Token 持久化 — .env 写回 
function persistTokensToEnv() {
  let content = readFileSync(ENV_PATH, 'utf-8');
  const aliveTokens = tokenPool
    .filter(t => t.token && !t.dead).map(t => t.token);
  if (aliveTokens.length === 0) return;

  const line = `DS_TOKENS=${aliveTokens.join(',')}`;
  const lines = content.split(/\r?\n/);
  let found = false;
  for (let i = 0; i < lines.length; i++) {
    if (lines[i].startsWith('DS_TOKENS=')) {
      lines[i] = line; found = true; break;
    }
  }
  if (!found) lines.push(line);
  writeFileSync(ENV_PATH, lines.join('\n'));
}
